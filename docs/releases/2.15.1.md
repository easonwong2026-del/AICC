# AICC v2.15.1 / macOS Build 30

控制台交互修复与 Magpie 借用授权 401 兜底优化版本（合并 PR #132）。存储结构、RPC 协议与授权优先级均未改动。

## 中文

### 账号详情页折叠区整行可点击（#132）

- 解决 macOS 原生 `DisclosureGroup` 仅左侧小三角可点、点击标题文字「授权详情 / 奖励 / 账号信息 / 配置详情」无响应的交互问题：新增 `ConsoleDisclosureSection` 替换账号详情页全部 6 处折叠区，支持整行点击展开/收起、悬停高亮与平滑旋转箭头。
- 当 WorkBuddy 账号仅有 Magpie 借用授权时，在「授权详情」内和自动旅行异常提示条上直接提供 **「添加自有授权」** 按钮，方便一键补充长期自有授权。

### Magpie 401 令牌未更新兜底与清晰引导（#132）

- 自动旅行遇到服务端 `401` 触发重同步后，若 Magpie 本地文件（`plugin-auth.json`）中的令牌与刚被拒绝的令牌完全相同（尚未刷新但标注过期时间仍在未来）：
  - 若账号同时拥有可用自有授权，立即无感兜底切换到自有授权完成请求；
  - 若账号仅有 Magpie 借用授权，返回清晰的中文错误引导（说明令牌已被服务端提前拒绝，需在 Magpie 重新登录或添加自有授权），不再只透传原始 HTML `401 Authorization Required`。

## English

### Full-Row Clickable Disclosure Sections (#132)

- Fixed the macOS SwiftUI `DisclosureGroup` usability issue where clicking the section title ("授权详情", "奖励", "账号信息", "配置详情") did not toggle expansion: introduced `ConsoleDisclosureSection` across all 6 account-detail sections with full-row hit testing, hover feedback, and a rotating chevron.
- Added a direct "添加自有授权" shortcut inside `授权详情` and on the inline travel-failure notice whenever a WorkBuddy account only has a Magpie borrowed authorization.

### Smarter Stale-Magpie 401 Fallback & Guidance (#132)

- When Buddy Travel receives HTTP 401 and `resync_magpie_access` reads back the exact same token from Magpie's `plugin-auth.json`:
  - Transparently falls back to a usable `own` authorization if the account has one;
  - Otherwise reports a clear localized explanation instructing the user to re-authenticate in Magpie or add an own authorization, instead of surfacing raw HTML 401 output.

## 安装 / Installation

- macOS：下载 `AICC-2.15.1.dmg`，核对 SHA-256；退出旧版 AICC 后拖入 `/Applications` 或 `~/Applications` 替换，再启动。
- macOS: Download `AICC-2.15.1.dmg`, verify its SHA-256, quit the running AICC, replace the app in `/Applications` or `~/Applications`, and launch it.
- 签名身份为本机固定自签证书 `AICC Local Code Signing`（未经 Apple 公证），需要 macOS 14+ 与 Apple Silicon，内置 Python 3.14 运行时；首次放行请按 DMG 内 `安装说明.txt` 在「系统设置 → 隐私与安全性」点「仍要打开」。
- Signed with the fixed local self-signed certificate `AICC Local Code Signing` (not notarized); requires macOS 14+ and Apple Silicon with bundled Python 3.14. See `安装说明.txt` inside the DMG if Gatekeeper holds the first launch.
