# AICC v2.14.1 / macOS Build 28

Bug 修复与控制台交互打磨版本（合并 PR #124 与 PR #125）。存储结构、RPC 协议与授权优先级均未改动。

## 中文

### 自动轮换不再"永远读不到空闲"（#124）

- 夜间轮换判断「你是否在用这台机器」时，只查 `ioreg -c IOHIDSystem -d 1`。
  在 macOS 26/27 上这条查询只回 `Root`：`IOHIDSystem` 不再作为 IOService 暴露，
  `HIDIdleTime` 一条都没有。于是每一轮都判「读不到空闲」，按设计保守推迟，
  到窗口尾部就记成 `skipped` —— 定时轮换永远不会开始（手动切换不受影响，所以看起来"手动能切"）。
- 现在两段式读取：先窄查询，拿不到再 `ioreg -l`（本机 0.16s）。两段都失败仍然返回
  「不知道」，**不会**据此认定你不在用，也不改 120 秒阈值与 60 秒心跳。
- 顺带把 `ioreg` 换成绝对路径 `/usr/sbin/ioreg`：GUI 进程的 `PATH` 不保证带 `/usr/sbin`。

### 借用授权不再"重新授权了还显示已过期"（#124）

- 一个账号同时有 Magpie 借用授权和自有授权时，界面的授权状态读的是账号镜像列。
  镜像里的 `token_expires_at` 是**导入那一刻的快照**；Magpie 自己换过令牌之后，
  AICC 里那份快照不会更新，界面就把一份可用授权一直显示成「已过期」。
- 现在 `sync_mirror` 选中 Magpie 授权时会现读 `plugin-auth.json` 的 `expires`：
  只更新时间，不动令牌、不改首选来源、不改授权优先级、不影响 Broker 的读取。
  文件读不到就保留原值 —— 宁可用旧快照，也不把「不知道」写成「已过期」。
- 刷新只更新到期时间，不会把授权标成 expired、不写 `last_error`、不要求重新登录。

### 10 分钟静默刷新、授权详情到期对齐与交互打磨（#125）

- **统一账号刷新协调器与 10 分钟前台定时刷新**：收敛冷启动、手动刷新、窗口激活、切页与前台定时五类入口；
  严格分离 `lastSuccessAt`、`lastAttemptAt` 与 `lastError`，刷新失败绝不推进成功时间，保留旧快照并标示「已过期」；
  加入并发防重、代次保护、失败指数退避（30s → 上限 600s）与零延迟忙循环保护；
  `workerUnavailableMessage` 改为在 `ensureWorkerReady()` 检查之后懒读取 `workerFailureText`；
  仅主窗口在前台且位于总览/AI 账号页时每 10 分钟只读刷新一次，页头显示「账号更新于 HH:mm」。
- **授权详情与总览状态对齐**：每条授权行展示到期日期与动态有效状态（支持带小数秒 ISO 8601），
  账号卡片、`authorizationProblem` 与总览汇总统一对齐借用授权的动态状态，自有授权保持隔离。
- **后端只读性能优化**：`account-worker` 在同一次 RPC 读取内通过 `MagpieLoginsCache`（`OnceCell`）复用 Magpie 登录文件，
  避免 N 个账号场景下重复读取与解析。
- **轻量交互打磨**：侧边栏补齐账号异常/任务失败微计数；新增 `⌘R`（刷新）、`⌘,`（设置）、`⌘1~⌘4`（切页）快捷键；
  补充列表行与按钮原生 Hover 反馈，Qoder 提示条增加「知道了」关闭按钮。

## English

### Scheduled rotation no longer reports "idle state unreadable" (#124)

- The rotation guard reads HID idle time with `ioreg -c IOHIDSystem -d 1`. On macOS 26/27 that
  query returns only `Root` — `IOHIDSystem` is no longer exposed as an IOService — so every tick
  concluded "cannot tell whether you are away", deferred by design, and eventually recorded the
  night as `skipped`. Scheduled rotation could never start; manual switching was unaffected.
- The probe is now two-step: the narrow query first, then a full `ioreg -l` (0.16 s here). If both
  fail it still returns "unknown" rather than assuming you are away; the 120-second threshold and
  the 60-second heartbeat are unchanged. `ioreg` is addressed by absolute path.

### Borrowed authorisations stop showing "expired" after re-authorising (#124)

- When an account has both a Magpie link and its own login, the UI reads the account mirror, whose
  `token_expires_at` was a snapshot taken at import time. Once Magpie rotated its token that
  snapshot went stale and a perfectly usable authorisation was displayed as expired.
- `sync_mirror` now reads `expires` from `plugin-auth.json` when the Magpie row is selected: expiry
  only — no token copied, preferred source unchanged, broker untouched. If the file cannot be read
  the old value is kept.

### 10-minute foreground refresh, auth expiry alignment & console polish (#125)

- **Unified refresh coordinator & 10m foreground auto-refresh:** consolidates initial load, manual refresh,
  window activation, page entry and scheduled ticks; separates `lastSuccessAt`, `lastAttemptAt` and `lastError`
  so failed refreshes keep the previous snapshot marked stale; adds in-flight deduplication, generation
  fencing, exponential backoff (30s up to 600s), spin prevention, lazy `workerFailureText` lookup, and
  a header "账号更新于 HH:mm" freshness label.
- **Auth row & fleet consistency:** per-authorization expiry dates (including fractional-second ISO 8601)
  and dynamic effective status match account cards and overview summaries while keeping own grants isolated.
- **Read-only backend optimization:** `account-worker` caches `plugin-auth.json` once per RPC call via
  `MagpieLoginsCache` (`OnceCell`).
- **Console polish:** sidebar attention badges, keyboard shortcuts (`⌘R`, `⌘,`, `⌘1–⌘4`), native hover
  states and a dismiss button on the Qoder notice banner.

### Tests

- Eight idle-probe cases plus an `#[ignore]`d real-machine check; four mirror cases plus `MagpieLoginsCache`
  reuse and auth isolation tests; and the two date-bound fixtures that had already started failing on
  main are now far-future.
- Swift adds `ConsoleAccountsRefreshTests`, `ConsoleOverviewAttentionTests`, and expanded `ConsoleModelsTests`.

- **强辨识离线态与新版设置弹窗**：离线时顶栏显示黑底反白 `OFFLINE` 胶囊 + 虚线提示横幅；设置弹窗新增实线输入框、TLS 1.3 指纹显示与**布局 / 排序 / 服务商筛选**。
