# AICC v2.12.0 / macOS Build 22

## 中文

- **新增 AICC 看板小组件**（large）：四页自动轮播 —— 总览（成功率环、调用、错误、剩余额度、今日 Token）、请求（最近模型、状态、延迟、平均 TTFT、今日 Token、最近三条请求）、会话（30 天会话数、总 Token、估算费用、最常用模型）、上下文（缓存命中率与 token 构成）。每页 15 秒，两轮后重新读一次 Magpie。
- **手动翻页停住 5 分钟**：页脚 `‹` `›` 立即翻页并显示「手动」徽章，`⟳` 立刻重读数据；不点则从停住那页继续轮播。
- **翻页走深链，不用 App Intents**：桌面小组件的 `Button(intent:)` 需要 Xcode 生成的 App Intents 元数据，手工打包（仅 Command Line Tools + ad-hoc 签名）下点击会被系统静默丢弃。页脚改用 `Link` + `aicc-widget://board/next|previous`，由主机 App 投递翻页请求。代价是点一下会短暂唤起 AICC。
- **可读性重做**：正文从 11pt 提到 12pt（区块标签、卡片标题、请求行、页脚摘要整体上调一档），大数字不动；页脚控件 22→27pt 并换成更亮的底色与可见描边；总览环形与右侧卡片等高、会话页把「最常用模型」提上来，消掉页面中部的空洞。
- **修复**：请求页在字号变大后摘要行被页脚压住；窄卡片里的「剩余额度」出现省略号；`aicc-widget://board/<任意路径>` 会静默往回翻、步长 2 只翻一页。
- **新增测试**：`BoardCommandTests`（翻页请求的投递、方向、时间戳幂等）；`scripts/smoke-test-board-visual.sh` 扩到 33 张离屏渲染，覆盖深色 / 浅色 / 变暗 / 空数据 / 陈旧 / 手动态。
- **版本**：AICC 2.12.0，macOS Build 22。仍为 ad-hoc 签名、未公证，首次打开需右键 → 打开。
- **校验和**：`AICC-2.12.0.dmg` SHA-256 `48c8a6c4edbbfa26389ec4f461ac5db1645e4fd3c210b4d0bd2ff3db35421460`。

## English

- **New AICC usage board widget** (large): four pages that rotate on their own — overview (success-rate ring, calls, errors, remaining quota, today's tokens), requests (latest model, status, latency, average TTFT, today's tokens, three recent requests), sessions (30-day sessions, total tokens, estimated cost, top model) and context (cache hit rate and token mix). Fifteen seconds a page, then two loops before Magpie is read again.
- **Manual paging holds the page for five minutes**: the footer's `‹` `›` turn a page immediately and mark the tile 手动; `⟳` re-reads the data now. Left alone, the carousel resumes from the page it stopped on.
- **Paging uses links, not App Intents**: `Button(intent:)` in a widget is routed through App Intents metadata that only Xcode's build phase produces. On a hand-built bundle (Command Line Tools only, ad-hoc signature) the system drops the tap without a word. The footer is now a `Link` to `aicc-widget://board/next|previous`, and the host app posts the turn. The cost is that tapping brings AICC forward for a moment.
- **Readability pass**: body type moves from 11pt to 12pt (section labels, card titles, request rows, the muted summary), hero numbers unchanged. Footer controls grow from 22 to 27pt with a lighter surface and a visible border, and two layouts lose the hole in the middle — the overview ring now matches the card grid, and 会话 keeps its top model next to the cards.
- **Fixes**: the requests page no longer pushes its summary line under the footer at the larger type size, 剩余额度 no longer truncates in narrow cards, and `aicc-widget://board/<anything>` no longer pages backwards or treats a step of two as one.
- **New tests**: `BoardCommandTests` covers the shared-domain handshake (direction, stamp, idempotence); `scripts/smoke-test-board-visual.sh` now renders 33 offscreen images across dark, light, dimmed, empty, stale and held states.
- **Version**: AICC 2.12.0, macOS Build 22. Still ad-hoc signed and not notarized; first launch needs right-click → Open.
