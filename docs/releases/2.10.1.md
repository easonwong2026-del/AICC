# AICC v2.10.1 / macOS Build 14

## 中文

- 桌面 Widget 使用等宽等高的圆角卡片、统一字号和柔和底色；支持 Small／Medium、浅色／深色及中英文。
- 默认保留服务／账号名、主要百分比、积分和余额，去掉冗余品牌标题、正常状态点和 W 前缀；已满的次级 5h 额度不再重复显示。
- 5h 不足时保留百分比，周额度缺失时明确回退到 5h；保留缓存、不可用和登录提示，以简短状态替代原始诊断码。活动账号通过字重区分，刷新按钮位于右下角。
- 视觉回归覆盖 364 种组合，并检查卡片边界对称；加入现有 Swift CI。
- Android 版本不变，继续使用 [v2.9.0 的 AICC-Poke4S-1.2.6.apk](https://github.com/easonwong2026-del/AICC/releases/download/v2.9.0/AICC-Poke4S-1.2.6.apk)。

## English

- Equal-sized rounded cards, consistent typography and soft surfaces for Small and Medium desktop widgets, in light/dark appearance and Chinese/English.
- Keeps service/account names, primary percentages, points and balances. Removes redundant branding, healthy status dots and W prefixes; full secondary 5h quota is hidden.
- Reduced 5h quota remains visible, with explicit 5h fallback when weekly quota is missing. Cache, unavailable and sign-in notices use short summaries instead of diagnostic codes. Active accounts use heavier type; refresh is at the bottom right.
- Visual regression covers 364 combinations and checks tile-bound symmetry; included in the existing Swift CI.
- Android remains unchanged; use the existing APK linked above.

## Installation / 安装

- Download `AICC-2.10.1.dmg`, verify `AICC-2.10.1.dmg.sha256`, and drag AICC into `/Applications` to replace the previous version. / 下载 DMG，核对 SHA256 后拖入 `/Applications` 替换旧版。
- Same ad-hoc signing as v2.10.0; not Apple-notarized. Requires macOS 14+, Apple Silicon and Python 3.10+; Python is not bundled. / 沿用 v2.10.0 的 ad-hoc 签名，未经 Apple 公证；需要 macOS 14+、Apple Silicon 和 Python 3.10+，DMG 不含 Python 解释器。
- Existing widget configuration and stored application data remain compatible. / 现有 Widget 配置和应用数据保持兼容。
