# AICC v2.15.0 / macOS Build 29

应用内更新检查正式上线 + 全栈稳定性、内存与资源泄漏治理版本（合并 PR #127、#128、#129、#130、#131）。存储结构、RPC 协议与授权优先级均保持兼容。

## 中文

### 应用内更新检查正式上线（#131）

- **更新引擎安全与可靠性加固**：
  - `UpdateInfo` 改为前向兼容解码，安全忽略未来扩展字段（如 `edSignature`），并预留可选 `sha256` 与 `releaseSummary`。
  - 联网前先校验本机 `currentVersion`；同时比较 SemVer 与同版本号下的 `build` 递增，并根据 `minimumSystemVersion` 校验本机 macOS 系统版本（不满足时给出 `.incompatibleSystem` 提示）。
  - 使用 `URLSession.bytes(for:)` 流式字节上限检查（1 MiB），防止超大响应占满内存；重定向与最终响应均强制要求 HTTPS + 受信任 GitHub/配置域名；`AICC_UPDATE_MANIFEST_URL` 环境变量覆盖仅在 `#if DEBUG` 下生效；SemVer 2.0.0 严格拒绝预发布数字前导零，并通过 Swift 6 严格并发零警告编译。
- **设置页、主控制台与菜单栏三端联动**：
  - **设置 → 常规 → 关于与更新**：直接展示当前版本与 Build 号、24 小时节流自动检查开关（默认开启，静默检查不弹窗）、上次检查时间，以及一键「检查更新 / 下载安装包 / 更新说明 / 忽略此版本」。
  - **菜单栏**：新增「检查更新…」快捷项；检测到未忽略新版本时在顶部动态显示「发现新版本 vX.Y.Z…」并同步更新图标 tooltip；应用启动 5 秒后自动在后台执行节流检查。
  - **主控制台侧边栏**：发现新版本时在左下角展示温和的内联提示条，点击直达设置页更新区。
- **发布与 CI 护栏**：新增 `scripts/validate-update-manifest.sh` 并接入 CI；`scripts/release-publish.sh` 改为动态读取构建产物 `Info.plist` 中的 `LSMinimumSystemVersion`；`UpdateServiceTests` 扩充至 21 个单元测试（含真实 `updates/aicc-update.json` 解码测试）。

### WorkBuddy 临时登录态恢复修复（#128）

- 轮换恢复原账号成功时正确结清遗留的临时恢复标记，并补充 UID 不匹配保护，避免本机已有正常授权登录账号时界面仍误显「临时登录」。

### 全栈内存、管道、会话、快照与 TLS 泄漏修复（#129）

- **macOS 端**：及时清理 `AccountWorkerClient` 的管道 `readabilityHandler` 与请求超时 `DispatchWorkItem`；在 `AccountWorkerManager` 重启前释放旧客户端；在 `AICCAppDelegate` 退出时停止所有后台任务与子进程；修复 `ServerManager` 与 `ConsoleAccountsAutoRefreshScheduler` 弱引用捕获；消除 `UpdateService` 中 `URLSession` 与代理循环引用；替换登录弹窗定时器并缓存二维码图像。
- **Rust `account-worker`**：为 `workbuddy_auth` / `qoder_auth` 会话表加入过期裁剪与上限；复用全局 `OnceLock<reqwest::Client>`；为成长调度器增加 RAII `TickGuard`；服务启动时清理孤立临时文件；在 WorkBuddy 切换回滚/恢复/结清后及时清理明文切换快照。
- **Python 桥接服务 (`server.py`)**：将局域网 TLS 握手从主 accept 线程移至连接处理线程（防止慢客户端阻塞合法 HTTPS 请求），修复 `host_id` 锁文件句柄泄漏，并保持失败握手的立即重置语义与回环轮询行为。

### 代码结构重构、死代码清理与测试恢复（#127、#130）

- 拆分 Rust `handlers` 模块并消除全部编译警告（#127）。
- 清理 `android/tls-probe`、废弃脚本、旧版 OpenCodex 测试夹具、未用 Rust `cbc` 依赖与死代码；在 `Package.swift` 中恢复 36 个被跳过的 Swift 单元测试（`ActivityModelsTests`、`WorkerQuotaModelsTests`）；为 `widget-health.log` 增加体积上限保护（#130）。

## English

### In-App Update Checker & Experience (#131)

- **Hardened update engine:** forward-compatible `UpdateInfo` decoding (optional `sha256` and `releaseSummary`, unknown future keys safely ignored), pre-network `currentVersion` validation, SemVer + same-version `build` comparison, `minimumSystemVersion` macOS compatibility checks (`.incompatibleSystem`), streaming 1 MiB byte-cap via `URLSession.bytes(for:)`, HTTPS + trusted GitHub/configured host checks on redirects and responses, `#if DEBUG`-gated `AICC_UPDATE_MANIFEST_URL`, strict SemVer 2.0.0 prerelease leading-zero rejection, and zero warnings under Swift 6 strict concurrency.
- **Settings, Console & Menu Bar integration:** Settings → General → About & Updates displays current version/build, a 24-hour silent auto-check toggle (default ON), last-checked time, and one-click Download / Release Notes / Ignore Version actions; Menu Bar adds "Check for Updates…" plus a dynamic update entry and tooltip; Main Console sidebar displays a non-intrusive inline update banner.
- **Release & CI guardrails:** added `scripts/validate-update-manifest.sh` to CI, updated `scripts/release-publish.sh` to read `LSMinimumSystemVersion` dynamically from `Info.plist`, and expanded `UpdateServiceTests` to 21 unit tests (including decoding the real `updates/aicc-update.json`).

### WorkBuddy Stale Temporary-Restore Fix (#128)

- Settles temporary restore metadata on rotation recovery and guards against UID mismatches so locally authorized accounts are not mislabeled as temporary logins.

### Full-Stack Resource, Session, Snapshot & TLS Leak Fixes (#129)

- **macOS:** clears pipe `readabilityHandler`s and request timeout `DispatchWorkItem`s, stops prior worker clients on restart, cancels background tasks on termination, fixes `[weak self]` loops, breaks `UpdateService`'s `URLSession` delegate retain cycle, and replaces sheet polling timers / redundant QR renders.
- **Rust `account-worker`:** prunes expired/capped auth sessions, shares `OnceLock<reqwest::Client>`, adds RAII `TickGuard`, sweeps orphan JSON files on startup, and removes plaintext switch snapshots once settled.
- **Python bridge (`server.py`):** performs LAN TLS handshakes off the accept thread so stalled TCP peers cannot block legitimate HTTPS requests, fixes lock descriptor leaks, and preserves failed-handshake reset semantics.

### Refactoring, Dead-Code Cleanup & Restored Tests (#127, #130)

- Split Rust `handlers` module with zero compiler warnings (#127).
- Removed orphaned fixtures, deprecated scripts, unused Rust `cbc` dependency, and dead UI helpers; bounded `widget-health.log`; restored 36 previously skipped Swift unit tests in `Package.swift` (#130).

- macOS: Download `AICC-2.15.0.dmg`, verify its SHA-256, quit the running AICC, replace the app in `/Applications` or `~/Applications`, and launch it.
