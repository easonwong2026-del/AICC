# AICC v2.11.0 / macOS Build 16

## 中文

- **AICC 不再只认 Codex**：额度数据契约升到 `schema_version: 3`，Magpie 返回的任意服务商、任意窗口名都能显示；订阅窗口、套餐、余额三类全部支持，未知服务商也不会被丢弃。
- **按真实语义显示**：服务商自己的用量文本（如 `35 / 40`）优先，其次剩余百分比，都没有就显示未知；余额不换算成百分比，没有重置时间不推算。积分类额度只显示**还剩多少**（`4650 积分`，右侧 `共 4727`）。
- **桌面小组件**：Small 2 张、Medium 4 张，支持一个账号多个窗口与 `+N` 溢出；设置里新增「选择额度…」，可以按服务商 → 账号 → 窗口勾选要显示的项目（例如只显示 Gemini 的 7 天额度），勾选顺序即显示顺序。
- **小组件配色与可见性**：每个服务商一个色相，剩余 ≤15% 转琥珀；修复两个真问题——刷新失败不再让整块回退成占位符（改为先读缓存再刷新），以及 macOS 26 变暗模式下卡片变成白块吞掉文字。
- **墨水屏整屏重做**：总览页用一张焦点卡显示最危险的额度（超大数字 + 上标单位 + 粗进度条 + `2 时 34 分后重置`），下面三行账号摘要；窗口数 ≥3 的账号另有详情页平铺全部窗口。修掉分隔线压字、基线错位、`+5 个窗口` 看不到、缺总量、品牌不一致等问题。
- **账号匿名**：展示快照、缓存与日志只保留稳定匿名 id 与首字符标签，不写入邮箱、原始账号名或任何凭据。
- **版本**：AICC 2.11.0，macOS Build 16；APK 1.2.6（versionCode 12，与既有安装同一证书，可直接覆盖升级）。

## English

- **AICC no longer hard-codes Codex**: the quota contract is now `schema_version: 3`, so any provider and any window name Magpie reports can be shown. Subscription windows, plans and balances are all supported; unknown providers are never dropped.
- **Semantics over guesses**: the vendor's own usage text wins (`35 / 40`), then a remaining percentage, otherwise "unknown". Balances stay money, and a window without a reset time is not given a fabricated one. Credit windows report what is left (`4650 credits`, `共 4727`).
- **Widget**: two cards on Small, four on Medium, with multiple windows per account and `+N` overflow. A new "选择额度…" sheet lets you tick windows per provider and account (say, only Gemini's 7-day window); the tick order is the display order.
- **Colour and legibility**: one hue per provider, amber under 15%. Two real bugs fixed — a failed refresh no longer blanks the tile (read the kept report first, then refresh), and macOS 26's dimmed (accented) rendering no longer turns cards into white slabs that swallow the text.
- **E-ink panel rebuilt**: the overview leads with the window closest to empty (oversized number, superscript unit, thick bar, relative countdown) and three summary rows; accounts with three or more windows get a page of their own. Fixes the divider striking through the reset line, mismatched baselines, the dead-end "+5 windows", the missing total and the inconsistent branding.
- **Account anonymity**: snapshots, caches and logs keep only a stable anonymous id and a first-character label — no email, raw account name or credential.
- **Versions**: AICC 2.11.0, macOS Build 16; APK 1.2.6 (versionCode 12, same certificate as before, so it upgrades in place).

## 安装 / Installation

- macOS：下载 `AICC-2.11.0.dmg`，核对 SHA256；退出 AICC 后将应用拖入 `/Applications` 替换旧版，再启动 AICC。小组件的 kind、共享设置域与既有实例配置保持不变，不用重新添加。
- macOS: Download the DMG, verify its SHA256, quit AICC, replace the app in `/Applications`, then launch it. The widget kind, its shared settings domain and existing instances are unchanged.
- 沿用 ad-hoc 签名，未经 Apple 公证；需要 macOS 14+、Apple Silicon 和 Python 3.10+。DMG 内置完整服务器源码，不含 Python 解释器。
- Uses ad-hoc signing without Apple notarization. Requires macOS 14+, Apple Silicon and Python 3.10+; the server source is bundled, Python itself is not.
- Poke4S：安装 `AICC-Poke4S-1.2.6.apk`，与 Mac 连接同一 Wi-Fi；先长按屏幕打开设置，选择服务器并输入 Mac AICC 生成的 8 位配对码。
- Poke4S: Install the APK, join the same Wi-Fi as the Mac, long-press the panel, pick the server and enter the 8-digit pairing code AICC shows.
- 墨水屏桥接是明文局域网 HTTP，只适合可信网络；升级 Mac 端时请一并升级 APK。
- The e-ink bridge is plain LAN HTTP and belongs on a trusted network only; upgrade the APK together with the Mac app.
